# JioTV and Extras: Which Account Do You Need?

JioTV has two possible content sources. Start with **JioTV** if you want live channels. **Extras** is an optional connection for additional channels, movies and shows. The older name **TV+** may appear in older guides or settings.

| | JioTV | Extras (TV+) |
| --- | --- | --- |
| Main use | Live television and programme information | Additional channels and available on-demand content |
| Connection | Sign in with the Jio mobile-number OTP flow | Enable Extras in server configuration and connect the separate Extras account |
| Required on a new server? | Needed for JioTV streams | No, disabled by default |
| Content access | Depends on your JioTV plan and the channel | Depends on provider subscription and playback rights |

## Check which source is active

1. Open **Settings** in the web interface.
2. Find the **JioTV** account card. If it says **Not logged in**, use **Send OTP** to connect.
3. If the server has Extras support enabled, look for its connection controls or status. A connected Extras account may add content and a small active icon in the header.
4. Open **Channels**. Use **Extra channels only** if you want to inspect the optional source. If Extras is disconnected, its content might be unavailable.

![Real Settings screen showing a disconnected JioTV account. Extras is disabled in this example.](../images/settings-no-account.png)

The screenshot is from a clean installation with no account connected. Your screen may include extra account controls when Extras is enabled. The existence of a channel tile never guarantees permission to play it.

## Understand labels and restrictions

**Subscription required** means you may need a plan or additional rights. **Unavailable** can also mean your account is disconnected, the provider rejected playback, the programme is region restricted, or the browser does not support its DRM system. JioTV cannot unlock subscriptions or bypass DRM.

If you need more channels, check the subscription with the provider before changing server settings. See [Connect a JioTV account](../account-connect-jiotv/index.md), [Connect Extras](../account-extras/index.md) and [Why a channel will not play](../troubleshooting-channels-and-playback/index.md).
