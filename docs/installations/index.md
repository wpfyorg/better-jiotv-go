# Install JioTV

JioTV runs as a server on a computer or router. Pick the guide for the system where the server will run:

- [Linux](../installations-linux/index.md), including [Raspberry Pi and other SBCs](../installations-sbc/index.md)
- [macOS](../installations-macos/index.md)
- [Windows](../installations-windows/index.md)
- [OpenWrt](../installations-openwrt/index.md)
- [Android with Termux](../installations-termux/index.md)
- [Docker](../installations-docker/index.md)
- [Docker Compose](../installations-docker-compose/index.md) for a reusable container setup
- [Manual release binary](../installations-manual-binary/index.md) for verified standalone downloads
- [Build from source](../installations-build-from-source/index.md)

The `full` variant includes the browser interface. The `slim` variant is headless and intended for IPTV clients or systems without a browser interface. Release downloads are checked against the release's SHA-256 manifest by the supplied installers.

After installation, complete [first launch](../getting-started-first-launch/index.md). Keep the server on a trusted network; see [network access and HTTPS](../configuration-network-security/index.md).
