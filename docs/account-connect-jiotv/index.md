# Connect Your JioTV Account

The JioTV account supplies channels from your account. It is separate from the admin password you use to open this server.

![JioTV connection card in Settings before an account is connected](../images/settings-no-account.png)

1. Sign in to the web interface with the server's admin password.
2. Open **Settings** and find the **JioTV** card.
3. Enter the 10-digit mobile number for your JioTV account and select **Send OTP**.
4. Enter the code sent to that number, then select **Log in**.
5. Check that the card says **Logged in**, then return to **Channels**.

**Expected result:** the JioTV account status is logged in and the channel list can load the channels available to that account. A channel may still require a subscription or be unavailable from the provider.

If the OTP fails or expires, request a fresh code and enter it promptly. If the channel list is empty, refresh the page and check the account status in Settings.

For first-time server setup, see [First Launch and Admin Setup](../getting-started-first-launch/index.md). To connect the optional source, see [Connect Extra Channels](../account-extras/index.md).

To replace an existing account, follow [Switch to Another JioTV Account](../account-switch-jiotv/index.md).
